# Regression Cases

## Goal

为 `TextGrabber` 提供一组可重复执行的人工回归检查，重点覆盖：

- 快捷键
- 截图
- 权限
- OCR 结果展示
- 设置修改

## Scope

当前回归主要关注真实工具 `TextGrabber`，预览宿主 `TextGrabberPreview` 仅用于 UI 辅助观察，不作为主回归结论依据。

## 执行方式

每次较大改动后，至少执行一轮高优先级用例。

建议记录：

- 执行日期
- 执行环境
- 是否通过
- 备注

## Cases

### Case 1：默认快捷键触发截图

目标：确认默认快捷键能正常进入截图流程。

步骤：
1. 启动 `TextGrabber`
2. 按下默认快捷键 `Control + Option`
3. 观察是否进入系统截图框选状态

预期：

- 成功进入系统截图交互
- 未出现崩溃或无响应

### Case 2：截图取消

目标：确认用户取消截图时流程安全结束。

步骤：
1. 触发截图
2. 在系统截图过程中按 `Esc` 取消

预期：

- 不出现错误弹窗
- 工具回到空闲状态
- 不残留错误 UI

### Case 3：首次权限缺失

目标：确认缺少屏幕录制权限时能正确提示。

步骤：
1. 关闭应用的屏幕录制权限
2. 重新触发截图

预期：

- 显示权限提示界面
- 可以从界面跳转系统设置

### Case 4：识别成功

目标：确认 OCR 主流程正常。

步骤：
1. 触发截图
2. 选择一块包含中英文文本的区域
3. 等待识别完成

预期：

- 结果面板正常出现
- 显示截图预览
- 显示可编辑识别文本

### Case 5：复制文本

目标：确认复制动作可用。

步骤：
1. 完成一次识别
2. 点击“复制文本”
3. 粘贴到任意文本编辑器

预期：

- 剪贴板内容与结果面板中的文本一致

### Case 6：重新识别

目标：确认重试流程可用。

步骤：
1. 完成一次识别
2. 点击“重新识别”

预期：

- 流程进入再次识别
- 面板状态正确切换

### Case 7：修改快捷键

目标：确认设置中的快捷键修改生效。

步骤：
1. 打开设置窗口
2. 修改快捷键
3. 使用新快捷键触发截图

预期：

- 新快捷键生效
- 旧快捷键不再触发
