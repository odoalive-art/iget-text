# Regression Cases

## Goal

为 `TextGrabber` 提供一组可重复执行的人工回归检查，重点覆盖：

- 快捷键
- 截图
- 权限
- OCR 结果展示
- 设置修改

## Scope

当前回归主要关注真实工具 `TextGrabber`，以真实运行态表现作为主回归结论依据。

## 执行方式

每次较大改动后，至少执行一轮高优先级用例。

建议记录：

- 执行日期
- 执行环境
- 是否通过
- 备注

## 当前建议最小回归集

针对多轮结果面板改动，建议至少执行以下用例：

- Case 2：截图取消
- Case 4：识别成功
- Case 5：复制文本
- Case 8：识别后自动聚焦文本区
- Case 9：窗口固定（Pin）
- Case 10：跟随鼠标模式下的固定窗口
- Case 11：结果文本编辑后复制
- Case 12：块编辑段落选择
- Case 13：设置页条件布局

## Cases

### Case 1：默认快捷键触发截图

目标：确认默认快捷键能正常进入截图流程。

步骤：
1. 启动 `TextGrabber`
2. 按下默认快捷键 `Control + Option`
3. 观察是否进入系统截图框选状态

预期：

- 成功进入系统截图交互
- 未出现崩溃或无响应

### Case 2：截图取消

目标：确认用户取消截图时流程安全结束。

步骤：
1. 触发截图
2. 在系统截图过程中按 `Esc` 取消

预期：

- 不出现错误弹窗
- 工具回到空闲状态
- 不残留错误 UI

### Case 3：首次权限缺失

目标：确认缺少屏幕录制权限时能正确提示。

步骤：
1. 关闭应用的屏幕录制权限
2. 重新触发截图

预期：

- 显示权限提示界面
- 可以从界面跳转系统设置

### Case 4：识别成功

目标：确认 OCR 主流程正常。

步骤：
1. 触发截图
2. 选择一块包含中英文文本的区域
3. 等待识别完成

预期：

- 结果面板正常出现
- 显示截图预览
- 显示可编辑识别文本

### Case 5：复制文本

目标：确认复制动作可用。

步骤：
1. 完成一次识别
2. 点击“复制文本”
3. 粘贴到任意文本编辑器

预期：

- 剪贴板内容与结果面板中的文本一致

### Case 6：重新识别

目标：确认重试流程可用。

步骤：
1. 完成一次识别
2. 点击“重新识别”

预期：

- 流程进入再次识别
- 面板状态正确切换

### Case 7：修改快捷键

目标：确认设置中的快捷键修改生效。

步骤：
1. 打开设置窗口
2. 修改快捷键
3. 使用新快捷键触发截图

预期：

- 新快捷键生效
- 旧快捷键不再触发

### Case 8：识别后自动聚焦文本区

目标：确认 OCR 结果出现后，文本区会自动获得焦点，方便直接键盘操作。

步骤：
1. 完成一次识别
2. 不点击文本区，直接观察插入光标位置
3. 直接按 `Command + A`
4. 再按一次 `Command + A`

预期：

- 文本区自动获得焦点
- 插入光标出现在文本末尾
- 光标使用一级语义色
- 块编辑开启时，第一次 `Command + A` 选择当前段落，第二次选择全文
- 块编辑关闭时，第一次 `Command + A` 直接选择全文

### Case 9：窗口固定（Pin）

目标：确认固定窗口后，面板不会因失焦自动消失。

步骤：
1. 完成一次识别
2. 点击结果面板头部 `Pin`
3. 切换到其他应用，或点击其他窗口

预期：

- `Pin` 按钮进入激活态
- 结果面板保持可见
- 返回应用后，结果面板仍能继续编辑和复制

### Case 10：跟随鼠标模式下的固定窗口

目标：确认“跟随鼠标”定位和 `Pin` 不会互相冲突。

步骤：
1. 在设置中将结果窗口位置改为“跟随鼠标”
2. 完成一次识别
3. 点击 `Pin`
4. 切换到其他应用，再返回
5. 点击面板内任意按钮，例如“拷贝文本”或“翻译”

预期：

- 固定后窗口不会因为失焦而消失
- 窗口不会因为后续点击按钮而突然跳到新的鼠标位置
- 返回应用后仍停留在原先位置

### Case 11：结果文本编辑后复制

目标：确认手工编辑后的内容会进入剪贴板，而不是回退成原始 OCR 结果。

步骤：
1. 完成一次识别
2. 在结果文本区修改几处文本
3. 点击“拷贝文本”
4. 粘贴到任意文本编辑器

预期：

- 剪贴板内容与当前文本区可见内容一致
- 不会回退成修改前的 OCR 结果

### Case 12：块编辑段落选择

目标：确认段落级全选、全文全选和复制内容一致。

步骤：
1. 在设置中开启“块编辑”
2. 识别一段至少包含两个段落的文本
3. 将光标放入第二段，按一次 `⌘A` 或 `⌃A`
4. 复制并粘贴，确认仅包含第二段
5. 再按一次 `⌘A` 或 `⌃A`，复制并粘贴
6. 用鼠标拖选一小段文本

预期：

- 第一次快捷键只选择光标所在段落，选中背景右缘连续
- 第二次快捷键选择全文
- 复制内容不包含视觉补齐产生的空格或字符
- 鼠标拖选恢复系统原生选择外观

### Case 13：设置页条件布局

目标：确认单页设置在三种截图激活方式下保持对齐。

步骤：
1. 打开设置窗口
2. 依次切换“组合键”“双击修饰键”和“Fn 键”
3. 检查截图识别、结果、翻译与文本三个分区

预期：

- 标签列与控件列稳定对齐，没有重叠或跳列
- 仅显示当前激活方式相关的快捷键或说明
- 翻译来源、显示位置和块编辑设置可正常保存
