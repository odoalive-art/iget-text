# Regression Cases

## Goal

为 `TextGrabber` 提供一组可重复执行的人工回归检查，重点覆盖：

- 快捷键
- 截图
- 权限
- OCR 结果展示
- 设置修改

## Scope

当前回归主要关注真实工具 `TextGrabber`，以真实运行态表现作为主回归结论依据。

## 执行方式

每次较大改动后，至少执行一轮高优先级用例。

建议记录：

- 执行日期
- 执行环境
- 是否通过
- 备注

## 当前建议最小回归集

针对最近几轮结果面板改动，建议至少执行以下用例：

- Case 2：截图取消
- Case 4：识别成功
- Case 5：复制文本
- Case 8：识别后自动聚焦文本区
- Case 9：窗口固定（Pin）
- Case 10：跟随鼠标模式下的固定窗口
- Case 11：结果文本编辑后复制

## Cases

### Case 1：默认快捷键触发截图

目标：确认默认快捷键能正常进入截图流程。

步骤：
1. 启动 `TextGrabber`
2. 按下默认快捷键 `Control + Option`
3. 观察是否进入系统截图框选状态

预期：

- 成功进入系统截图交互
- 未出现崩溃或无响应

### Case 2：截图取消

目标：确认用户取消截图时流程安全结束。

步骤：
1. 触发截图
2. 在系统截图过程中按 `Esc` 取消

预期：

- 不出现错误弹窗
- 工具回到空闲状态
- 不残留错误 UI

### Case 3：首次权限缺失

目标：确认缺少屏幕录制权限时能正确提示。

步骤：
1. 关闭应用的屏幕录制权限
2. 重新触发截图

预期：

- 显示权限提示界面
- 可以从界面跳转系统设置

### Case 4：识别成功

目标：确认 OCR 主流程正常。

步骤：
1. 触发截图
2. 选择一块包含中英文文本的区域
3. 等待识别完成

预期：

- 结果面板正常出现
- 显示截图预览
- 显示可编辑识别文本

### Case 5：复制文本

目标：确认复制动作可用。

步骤：
1. 完成一次识别
2. 点击“复制文本”
3. 粘贴到任意文本编辑器

预期：

- 剪贴板内容与结果面板中的文本一致

### Case 6：重新识别

目标：确认重试流程可用。

步骤：
1. 完成一次识别
2. 点击“重新识别”

预期：

- 流程进入再次识别
- 面板状态正确切换

### Case 7：修改快捷键

目标：确认设置中的快捷键修改生效。

步骤：
1. 打开设置窗口
2. 修改快捷键
3. 使用新快捷键触发截图

预期：

- 新快捷键生效
- 旧快捷键不再触发

### Case 8：识别后自动聚焦文本区

目标：确认 OCR 结果出现后，文本区会自动获得焦点，方便直接键盘操作。

步骤：
1. 完成一次识别
2. 不点击文本区，直接观察插入光标位置
3. 直接按 `Command + A`
4. 再按任意字母键或 `Delete`

预期：

- 文本区自动获得焦点
- 插入光标出现在文本末尾
- 光标颜色为主题橙色
- `Command + A` 能直接选中文本
- 输入或删除操作直接作用于结果文本区

### Case 9：窗口固定（Pin）

目标：确认固定窗口后，面板不会因失焦自动消失。

步骤：
1. 完成一次识别
2. 点击结果面板头部 `Pin`
3. 切换到其他应用，或点击其他窗口

预期：

- `Pin` 按钮进入激活态
- 结果面板保持可见
- 返回应用后，结果面板仍能继续编辑和复制

### Case 10：跟随鼠标模式下的固定窗口

目标：确认“跟随鼠标”定位和 `Pin` 不会互相冲突。

步骤：
1. 在设置中将结果窗口位置改为“跟随鼠标”
2. 完成一次识别
3. 点击 `Pin`
4. 切换到其他应用，再返回
5. 点击面板内任意按钮，例如“拷贝文本”或“翻译”

预期：

- 固定后窗口不会因为失焦而消失
- 窗口不会因为后续点击按钮而突然跳到新的鼠标位置
- 返回应用后仍停留在原先位置

### Case 11：结果文本编辑后复制

目标：确认手工编辑后的内容会进入剪贴板，而不是回退成原始 OCR 结果。

步骤：
1. 完成一次识别
2. 在结果文本区修改几处文本
3. 点击“拷贝文本”
4. 粘贴到任意文本编辑器

预期：

- 剪贴板内容与当前文本区可见内容一致
- 不会回退成修改前的 OCR 结果

备注：

- 当前已知问题：在“阅读优化”下修改文本后切到“原始文本”，仍会看到另一套模式文本，体验存在割裂感；该问题已记录，但不影响本用例判断“当前模式下的编辑内容是否可复制”
